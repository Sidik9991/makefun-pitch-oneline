One sentence, 218 characters, written for make.fun's "A Day of One-Line
Pitches" bounty: it talks a friend who has never coded into letting an AI
agent build their first app idea on make.fun. The pitch opens on the idea
the friend is already carrying around, asks only that they describe it in
plain words, promises a first version they can actually try — no coding, no
course — and closes on the part that makes saying yes feel safe: anything
they don't like, they can change.

`main.ts` (Node 22) writes that sentence to `/output/entry.txt`. Its
comments score six candidate sentences against the judge's brief, in the
brief's own order — persuasion, clarity, truth, warmth and craft — and name
the winner and why.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
